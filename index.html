Each slide needs a layout that serves its message and objects the author can edit.

Image generation makes it possible to explore layouts around the content of a slide. Turning a chosen design into a useful deck also requires accurate text, editable charts and a consistent visual style.

SlidePoise gives that creative process a structured workflow, supported by tools for visual measurement and PowerPoint construction. A shared content plan, style and asset library guide the Agent as it develops designs, builds editable slides and reviews the resulting deck.

How SlidePoise works

Content planning establishes the argument and evidence. Visual design assembles references and assets on a contact sheet, generates a slide image and checks it against the brief. Reconstruction combines the Agent’s interpretation with OpenCV measurements to build editable PowerPoint objects. The final review checks the rendered PowerPoint for content, consistency and fidelity to the generated image.

The Agent defines each slide’s message and evidence, then retrieves useful references, icons, logos or native component previews. A contact sheet brings those visual inputs together for image generation. The Agent reviews the resulting image for content, readability and layout before reconstruction. Reconstruct the design as editable objects

Once a design is chosen, its contents need to become PowerPoint objects. The Agent identifies what each element represents and which elements belong together. In this example, the bars, labels and values form one chart. OpenCV, a computer-vision library, measures its geometry so the renderer can rebuild it as an editable chart linked to its data.

Interpretation and measurement work together. The Agent reviews the measured regions and refines object boundaries when needed. The native build combines both inputs, then the Agent inspects the rendered slide and corrects any loss of meaning or visual fidelity.

Install SlidePoise

SlidePoise is built and tested with Codex and its native image tools. Claude Code and Qoder can use the same workflow with a connected image generator. You can also generate images in another app. The Agent prepares the prompt and reference files, then continues when you return the image.

What gets installed

Setup installs measurement and PowerPoint tools, registers the skill for detected Agent platforms, and prepares local slide previews. Your system may request administrator access for the preview tools.

  • An isolated Python environment in ~/.slidepoise/python with Pillow, python-pptx, NumPy and OpenCV.
  • PptxGenJS and JSZip in ~/.slidepoise/node.
  • Profiles and Library Sets in ~/.slidepoise, with the skill registered in the detected platform’s skills directory. Add --agent claude, --agent qoder or --agent codex to choose explicitly.

LibreOffice renders the PowerPoint and Poppler converts it into images for the Agent to review. Setup installs missing copies through Homebrew on macOS, winget on Windows, or apt on Debian/Ubuntu. Use an image generator connected to your Agent, or generate images in another app and return them to the Agent. Set this preference with your Agent or in the Console’s System settings.

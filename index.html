Each slide needs a layout that serves its message and objects you can edit.

Template-based workflows can limit how freely a slide’s layout responds to its content. Image generation makes it possible to explore layouts around the content of a slide. Turning a chosen design into a useful deck also requires accurate text, editable charts and a consistent visual style.

SlidePoise gives that creative process a structured workflow, supported by tools for visual measurement and PowerPoint construction. A shared content plan, style and asset library guide the Agent as it develops designs, builds editable slides and reviews the resulting deck.

01 · Content planning

Develop the slide’s message and evidence

The Agent works with your source material to establish the presentation’s argument and the purpose of each slide. Each brief records its main message, supporting content and visual requirements.

02 · Visual design

Generate slide images guided by content and references

The Agent retrieves slide references, icons and reusable components for the brief. It brings the selected material together in a contact sheet, then gives this visual guidance and the slide content to the image model.

03 · Reconstruction

Reconstruct the design as editable PowerPoint objects

The Agent identifies what each object means and which elements belong together. OpenCV measures the visible content inside those regions. The Agent uses both records, the source data and original assets to build editable PowerPoint objects.

Refine illustrations as separate artwork

For illustrations, the Agent can generate a separate, higher-resolution image with a transparent background. It checks the artwork against the slide design, then places it as an independent PowerPoint layer. Compare this detail from the editorial sample.

04 · Review

Check the PowerPoint against the design and brief

The Agent renders the PowerPoint and checks it against the chosen design and content brief. It corrects visual differences and checks consistency across the deck. Drag the divider to compare the design image with the finished PowerPoint.

Install SlidePoise

SlidePoise is built and tested with Codex and its native image tools. Claude Code and Qoder can use the same workflow with a connected image generator. You can also generate images in another app. The Agent prepares the prompt and reference files, then continues when you return the image.

What gets installed

Setup installs measurement and PowerPoint tools, registers the skill for detected Agent platforms, and prepares local slide previews. Your system may request administrator access for the preview tools.

  • An isolated Python environment in ~/.slidepoise/python with Pillow, python-pptx, NumPy and OpenCV.
  • PptxGenJS and JSZip in ~/.slidepoise/node.
  • Profiles and Library Sets in ~/.slidepoise, with the skill registered in the detected platform’s skills directory. Add --agent claude, --agent qoder or --agent codex to choose explicitly.

LibreOffice renders the PowerPoint and Poppler converts it into images for the Agent to review. Setup installs missing copies through Homebrew on macOS, winget on Windows, or apt on Debian/Ubuntu. Use an image generator connected to your Agent, or generate images in another app and return them to the Agent. Set this preference with your Agent or in the Console’s System settings.
